# Scripts

Här läggs framtida generatorer och valideringsscript.


## CI och GitHub Actions

- `ci_validate_project.py` – validerar att projekt, data och release hänger ihop.
- `ci_build_print_preview.py` – bygger preview-PDF:er för utskrift.
- `ci_package_release.py` – paketerar print-and-play-release.

- `build_print_and_play.py` – bygger komplett print-and-play-paket från källor.
