# Kortstil v0.4.1

## Ändring från v0.4

Efter visuell feedback justerades rubrikfältet.

### Problem i v0.4
- kortnamnet hade för lite vertikal luft
- rubrikfältet kändes för lågt
- titlar låg för nära separationslinjen

### Lösning i v0.4.1
- högre rubrikfält
- mer vertikal padding runt kortnamn
- dekorrader och effektfält flyttade ned något
- samma övergripande stil, men bättre proportioner

## Designprincip

Detta är fortfarande samma datastyrda styled SVG-system.  
Vi justerar proportioner i mallen, inte manuellt per kort.
