# Playtestlogg – Fyrens väktare

## Syfte

Den här filen används för att samla resultat från speltester.

Första målet är inte att bevisa att spelet är färdigt, utan att se om REGLERV3 fungerar vid bordet:

- förstår spelarna målet?
- förstår de sina tre handlingar?
- fungerar tempot?
- känns Mörker lagom hotande?
- blir matvalet intressant?
- går det att bygga Fyren innan Mörker når 0?
