# Första speltestet – checklista

## Version

**Fyrens väktare v0.7.0 – [PLAN2] Steg 4**

## Testmål

Testa om spelet går att spela från start till slut med nuvarande regler.

Fokusera på:

1. om spelarna förstår handlingarna
2. om A6-kortet räcker som spelhjälp
3. om brädet fungerar utan platsregler tryckta på rutorna
4. om Mörker skapar lagom press
5. om Bygga på Fyrplatsen känns tydligt

## Skriv ut

Minsta testpaket:

- A4-bräde:
  - `output/print/board/board-a4-REGLERV3-v0.7.0-rev2.svg`
- A6-referenskort:
  - `output/print/reference/reference-card-a6-REGLERV3-v0.7.0-rev12.svg`
  - eller A4-arket med fyra A6-kort
- Fyndkort och hotkort om de redan är utskrivna
- Regelbok:
  - `docs/rulebook.md`

## Använd ersättningskomponenter

Det går bra att använda:

- kuber, pärlor eller mynt som resurser
- valfria pjäser som spelarpjäser
- en liten markör för Mörker
- papperslappar om korten inte är utskrivna

## Före testet

Kontrollera:

- [ ] Brädet är utskrivet i liggande A4.
- [ ] A6-kortet är utskrivet.
- [ ] Mörkerspåret är lätt att markera.
- [ ] Resurser finns för trä, sten, mat och kristall.
- [ ] Fyndkort och hotkort finns.
- [ ] Någon har läst setup i regelboken.
- [ ] `docs/playtest-log.md` är redo att fyllas i.

## Under testet

Anteckna direkt när något är oklart.

Särskilt viktigt:

- [ ] Förstår spelarna att `Utforska` betyder att titta på platsens effekt?
- [ ] Förstår spelarna att `Bygga` bara kan göras på Fyrplatsen?
- [ ] Behöver någon fråga vad Basen gör?
- [ ] Används mat mest till extra handlingar eller Nattvakt?
- [ ] Är Stig-regeln enkel eller krånglig?
- [ ] Känns Grotta som ett intressant riskval?
- [ ] Är Mörkerspåret lätt att följa när det går nedåt?

## Efter testet

Svara kort:

1. Vad var tydligast?
2. Vad var mest oklart?
3. När kändes spelet mest spännande?
4. När stannade spelet upp?
5. Vilken regel glömdes?
6. Vilken komponent behövde mest förklaring?
7. Vill spelarna spela igen?

## Ändringsregel efter första testet

Gör inte många ändringar direkt.

Välj högst:

- 1 regeländring
- 1 balansändring
- 1 komponent-/layoutändring

Spara resten som observationer.
